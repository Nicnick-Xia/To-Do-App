# 📝 Todo App - Vercel Deploy

一个使用 Next.js + Tailwind CSS 构建的待办事项应用，部署在 Vercel 上。

## 功能

- ✅ 添加待办事项
- ✅ 标记完成/未完成
- ✅ 删除待办事项
- 💾 数据持久化（LocalStorage）
- 🎨 精美渐变 UI

## 本地运行

```bash
npm install
npm run dev
```

## 部署到 Vercel

项目已配置 Vercel，可以使用以下命令部署：

```bash
vercel --prod
```

或点击下方按钮：

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/todo-app-vercel)

## 技术栈

- Next.js 14 (App Router)
- Tailwind CSS
- LocalStorage 数据持久化
